# 文字コード体験

文字コードの違いを画面上で体験するためのローカルアプリです。ブラウザだけで動くため、HTML ファイルを直接開いても使えます。

## 起動方法

HTML を直接開く場合:

```text
public/index.html
```

ローカルサーバーで開く場合:

```bash
npm start
```

ブラウザで以下を開きます。

```text
http://127.0.0.1:4517
```

## できること

- Shift_JIS で保存して Unicode として読む、Unicode で保存して Shift_JIS として読む、という切り替えを体験
- 入力した文字を、選んだ文字コードで保存した時のバイト列を表示
- 同じバイト列を UTF-8 / Shift_JIS / EUC-JP / UTF-16LE で読んだ結果を比較
- 文字化け、読めないバイト、保存時に置き換わる文字を体験
- 文字ごとの Unicode 番号と UTF-8 のバイト列を確認
