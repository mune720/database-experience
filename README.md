# 図書館情報技術論　演習用

図書館情報技術論（司書課程）向けの、ブラウザ上で完結する演習用Webアプリ群です。

## 特徴

- トップページから各演習ページに移動
- データベース体験では、5テーブル構成（書籍・著者・所蔵・利用者・貸出）を操作
- 情報検索のしくみでは、検索方式の違いとディレクトリ型検索を体験
- 文字コードの違いでは、文字化け・符号化・Unicodeを体験
- データはこのブラウザのみに保存（ログイン不要、各自のデータは他人に見えない）
- 完全静的なHTML/CSS/JS（ビルド不要）

## ページ構成

- `index.html`：授業全体のトップページ
- `database.html`：データベース体験
- `search.html`：情報検索のしくみ
- `文字コードとデータ表現/public/index.html`：文字コードの違い

## ローカルでの確認

`index.html` をブラウザで開くだけで動作します。

## Vercelへのデプロイ

1. このリポジトリを GitHub にプッシュ
2. https://vercel.com/new で対象リポジトリを Import
3. 設定はデフォルトのまま Deploy
4. 発行されたURLを学生に配布

ビルド設定は不要（静的サイト）です。
