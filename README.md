# データベース体験アプリ

図書館情報技術論（司書課程）向けの、リレーショナル・データベース体験Webアプリです。

## 特徴

- 図書館の蔵書管理を題材に、5テーブル構成（書籍・著者・所蔵・利用者・貸出）を体験
- `BID0001` や `AID0001` など、主キーらしいIDでテーブル間の関連を確認
- 著者検索、所蔵冊数、著者別蔵書数、利用者登録数などの簡単な統計を可視化
- データはこのブラウザのみに保存（ログイン不要、各自のデータは他人に見えない）
- 完全静的なHTML/CSS/JS（ビルド不要）

## ローカルでの確認

`index.html` をブラウザで開くだけで動作します。

## Vercelへのデプロイ

1. このリポジトリを GitHub にプッシュ
2. https://vercel.com/new で対象リポジトリを Import
3. 設定はデフォルトのまま Deploy
4. 発行されたURLを学生に配布

ビルド設定は不要（静的サイト）です。
