公共図書館APIで蔵書検索を試す

地域の図書館が公開している検索APIを使うと、キーワード、著者名、ISBNから蔵書情報を取得できます。この記事では、授業用のサンプルとして検索結果をJSONで読む流れを整理します。

fetch("/api/books?q=地域資料")
  .then(response => response.json())
  .then(data => console.log(data.items));

内容は技術ブログですが、図書館サービス、情報検索、オープンデータにも関係するため、分類に迷いやすいページです。
